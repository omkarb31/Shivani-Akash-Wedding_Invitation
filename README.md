# Shivani & Akash — Wedding Invitation

Open `index.html` to choose between 12 completely different websites.

| Folder | Design | Layout idea |
|---|---|---|
| 01-classic-wine | Classic Wine | The original (unchanged) |
| 02-royal-maharaja | Royal Maharaja | Scroll "palace chapters", accordion pillars |
| 03-garden-blush | Garden Blush | Storybook: envelope, winding timeline, polaroids |
| 04-starry-night | Starry Night | Live star-field, constellation events, scroll-merging stars |
| 05-boho-terracotta | Boho Terracotta | Sidebar layout, tabbed events, masonry |
| 06-filmy-cinema | Filmy Cinema | Movie site: ticket gate, trailer, clapperboard, credits |
| 07-neon-sangeet | Neon Sangeet | Synthwave playlist, vinyls, now-playing bar |
| 08-editorial-issue | Editorial Issue | Fashion magazine with a book-cover gate |
| 09-passport-journey | Passport Journey | Passport, plane flying along a route, boarding passes |
| 10-zen-ink-scroll | Ink & Paper | Horizontal scroll painting, vertical type |
| 11-art-deco-deck | Art Deco Gala | Elevator gate, sunburst, swipeable event card deck |
| 12-pixel-quest | Pixel Quest | 8-bit game: HUD, level select, pixel-art photos |

Every folder is self-contained: its own `media/` (dummy video + photos) and, for 02–12, its own `shared/` engine
(`core.js`, `core.css`, `content.js` = English/Marathi text). Replace `media/dummy.mp4`, `bride.jpg`, `groom.jpg` with real ones.
